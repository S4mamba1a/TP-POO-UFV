# TP-POO
Repositório destinado à implementação do Trabalho Prático da disciplina de Programação Orientada à Objetos. O grupo é composto por: Almiro, Victor, Vitor, Eduardo, João Gabriel, Tadeu, Samuel e Joaquim.

O trabalho será um programa feito em linguagem Java chamado "A Última Risada". Ele simula um sistema de contratação de palhaços de aluguel. Algumas das características inicialmente planejadas são:
- Entidades Cliente, Palhaço, Contratante, Instrumento de Risada, Avaliação, entre outras.
- Funcionalidades como Contratação, Gerenciamento de Palhaços, Gerenciamento de Avaliações, Gerenciamento de Instrumentos, Ranking de Palhaços, entre outras.
